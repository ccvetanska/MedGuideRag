# Оценка

Скриптовете, данните и архивираните резултати зад числата в дипломната работа (раздели 4.2–4.7).

## Изпълнение

От папката `MedGuideRag/`, при спряно приложение:

```
.venv/Scripts/python.exe -m evaluation.<script>
```

Всеки скрипт отпечатва числата, които възпроизвежда.

| Скрипт | Възпроизвежда |
|---|---|
| `retrieval_eval` | сравнението на методите за извличане |
| `stemming_eval` | обработката на думите при BM25 |
| `calibrate_threshold` | прага за отказ |
| `input_coverage` | обхвата на представянето на откъсите |
| `grounding_eval` | оценката на проверката за неподкрепени подробности |
| `attribution_eval` | оценката на маркирането на източниците |
| `coverage_eval` | ефекта на проверката на ключовите понятия |
| `significance` | статистическите тестове |
| `gpu_benchmark` | времето за изпълнение на централния и на графичния процесор |
| `offline_check` | работата без мрежа |
| `figures` | графиките в `docs/figures/` |
| `final_eval` | окончателната оценка (стъпки `check`, `run`, `report`) |

## Данни и резултати

- `data/` – наборът за разработка, въпросите извън обхвата и наборът за окончателна оценка.
- `results/thesis/` – отговорите, класиранията и ръчните оценки, върху които са изчислени числата в текста. Скриптовете само ги четат.
